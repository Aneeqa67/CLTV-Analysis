# STRATEGIC PROFITATBILITY VIA CLTV OPTIMIZATION
This project leverages CLTV analysis using Python to assess customer profitability across marketing channels by integrating acquisition cost, revenue, and conversion metrics. Through data visualization and statistical inference, it identifies optimal acquisition strategies to maximize long-term revenue and customer value.

## Contents

* `CLTV Code`:  This script performs a detailed and visually enhanced analysis of Customer Lifetime Value (CLTV) using various plots to explore relationships between cost, revenue, conversion rate, and acquisition channels.
* `README.md`: This file.

## Usage

* Install the required dataset from http://kaggle.com/datasets/amirmotefaker/customer-acquisition-data
* In the PyCharm terminal, install the required Python packages: pip install pandas matplotlib seaborn
* Place your dataset file named customer_acquisition_data.csv in the root directory of the project and "Run" the .py file. Visualizations will appear one by one in pop-up windows.
